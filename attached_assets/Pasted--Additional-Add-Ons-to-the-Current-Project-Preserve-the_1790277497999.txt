## Journey Page

Create or update the Journey page with limited location access.

- Request location permission only on the Journey page or when the user selects “Find Nearby Stops.”
- Do not request location access on the login, Home, reporting, rewards, or SOS pages.
- Use location only to identify the nearest bus stop and recommend bus routes.
- Do not continuously track the child during normal, non-emergency use.
- Explain clearly to users why location permission is needed.

Include:

- “Use My Location” button
- Search field for the child’s destination
- Searchable bus routes and bus stops
- Nearest available bus stop
- Destination bus stop options
- Route duration
- Walking distance
- Number of transfers
- Delay information
- Service alerts
- Recommended route
- Option to choose another route

## Efficient Route Recommendation

Create an algorithm that recommends the most efficient route based on:

- Starting location
- Distance to the nearest bus stop
- Destination
- Total travel time
- Walking distance
- Number of transfers
- Current delays
- Service alerts
- Route availability

Prioritize routes with shorter travel time, fewer transfers, shorter walking distances, and fewer delays.

Clearly label the highest-ranked option:

“Recommended Route”
